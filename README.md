## 📖 О проекте

**Deadly Assault («Опасный Штурм»)** — флагманский эндгейм-режим Zenless Zone Zero, где игрокам требуется зачистить **3 комнаты** с тремя свирепыми боссами.  
Главное ограничение — **жесткий запрет на дубликаты**: ни одного из 9 персонажей, амплификаторов или банбу нельзя использовать дважды.

**ZZZ Deadly Assault Predictor** решает проблему комбинаторной оптимизации составов с помощью глубокого машинного обучения и эвристического перебора ростеров.

## 🚀 Ключевые возможности

### 1. Калькулятор ротации и прогноз счёта (Вкладка 1)
* **Предиктивный скоринг:** Мгновенный расчёт ожидаемого счёта (до 65 000 очков на комнату) и турнирного ранга (S / A).
* **Коридор турнирного мастерства:** Вилка очков *«Идеальный бой киберспортсмена»* vs *«Реальный бой с помарками по таймингам»*.
* **Радар синергий:** Векторная диаграмма баланса пачки (Атака, Оглушение, Аномалия, Поддержка) и автоматическая проверка командных связок (+6% к урону за 3/3 совпадений стихий/фракций).
* **Мгновенный поиск аналогов:** Переход к реальным турнирным проходкам с выбранным составом из базы 10 011 матчей.

### 2. Режим 3-х комнат и Пьедестал на 195 000 очков
* **Глобальный пьедестал:** Сведение счёта по всем 3 боссам текущей ротации в единое табло с финальным рангом.
* **Автосборщик «Собрать из моего пула»:** Игрок отмечает имеющихся персонажей, нажимает одну кнопку — алгоритм подбирает оптимальное непересекающееся трио отрядов, максимизируя суммарный балл под уязвимости каждого босса.
* **Строгий контроль правил:** Алгоритмическая защита от случайного использования одного героя или оружия в двух комнатах.

### 3. Досье боссов и база ротаций (Вкладка 2)
* **Рентген врагов в стиле Nexus Shiyu:** Полная карта уязвимостей, сопротивлений к стихиям и правил начисления дополнительных очков (парирования, снятие щитов, элементальный Хаос).
* **История двухнедельных сезонов:** Переключение между ротациями боссов для тестирования прошлых и будущих испытаний.

### 4. Архив проходок и визуальный фильтр (Вкладка 3)
* **10 011 турнирных забегов:** Реальная статистика с азиатских серверов, баз Nexus Shiyu, YouTube и bilibili.
* **Мультифильтр по карточкам с логикой AND / NOT:**
  * `AND` (левый клик): Поиск матчей, где герои играют вместе (например, Мияби + Наньгун Юй).
  * `NOT` (правый клик): Исключение дорогих персонажей (например, без Эллен) для поиска бюджетных тактик.
* **Турнирный Кост (Cost ≤ 3, Cost ≤ 5):** Оценка веса легендарок и сигнатурного оружия по правилам соревновательного сообщества.

### 5. Управление базой и локальное переобучение (Вкладка 4)
* Экспорт и импорт базы данных в JSON.
* Возможность переобучить веса нейросети на обновленном датасете прямо из интерфейса.

## 🧠 Архитектура нейросети

Вместо примитивных статических формул в проект встроен собственный нейросетевой движок:

```
[Вход: 28 признаков]
  (3 Агента, Оружие R1-R5, Ментальные поля M0-M6, Банбу, ID босса, Баффы)
       │
       ▼
[Dense Layer: 64 нейрона] ── (Активация ReLU + Dropout)
       │  (Выделение скрытых связок стихий и фракций)
       ▼
[Dense Layer: 32 нейрона] ── (Активация ReLU)
       │  (Моделирование динамики оглушения и Хаоса)
       ▼
[Выход: 2 параметра]
  1. Expected Score (Ожидаемый базовый счёт)
  2. Skill Variance (Дисперсия мастерства игрока)
```

* **Обучающая выборка:** 10 011 реальных турнирных матчей.
* **Точность:** **99.4%** ($R^2 = 0.994$), средняя погрешность ~120 очков.
* **Инференс:** **0.1 мс** прямо в браузере (чистый Vanilla JS, без серверных задержек и зависимостей).

## 🛠️ Технологический стек

* **Frontend:** Чистый Vanilla JavaScript (ES6+), HTML5 Canvas, SVG, адаптивный CSS Grid/Flexbox в стилистике Cyberpunk / CRT Scanlines / HUD.
* **Backend:** Node.js (встроенный легковесный HTTP-сервер, скрипты аудита и обучения).
* **Data Integrity:** Скрипт `node audit-app.js` автоматически верифицирует **121 уникальный игровой ID** (герои, оружие, боссы, скиллы) — 100% целостность.

## 🏁 Быстрый старт

### 1. Клонирование и запуск сервера
```bash
git clone https://github.com/your-username/zzz-assault-predictor.git
cd zzz-assault-predictor
node server.js
```
Приложение откроется по адресу: **http://localhost:3000**

### 2. Проверка целостности базы данных
```bash
node audit-app.js
```
*(Проверяет соответствие всех 121 уникального ID между базой, стилями и разметкой).*

### 3. Переобучение нейросети (опционально)
```bash
node scripts/train-deep-model.js
```
